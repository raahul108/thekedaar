### 📱 How to Install on Android
1. Click the **Download Android APK** button above.
2. Download the `thekedaar-v1.0.apk` file onto your phone.
3. Tap the file to install (if your phone asks for permission to install from browser, tap **Settings -> Allow from this source**).

### ☁️ Features
- **Monthly Labour Register:** Track worker names, categories, monthly base salary, and cash advances with automatic net payable calculations.
- **Company Bills Tracker:** Log work bills received from companies along with photo proofs.
- **Multi-Site Support:** Manage data across multiple construction sites separately.
- **Hindi & English Language:** Insert records in both languages seamlessly.
- **Real-Time Cloud Sync:** Log in from any device to access your data anywhere.
